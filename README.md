# 📋 Project Overview
4th year deep learning assignment 
This project aims to classify skin lesions into seven distinct categories using deep learning techniques. The dataset used is the HAM10000 (Human Against Machine with 10,000 training images) — a real-world dermatology image dataset publicly available on Kaggle.
We implemented and compared four CNN-based models to evaluate their performance on accuracy, efficiency, and generalization for medical image classification.
